# Zivakhata - AI-Powered Financial Ledger 📊🤖

Zivakhata is a full-stack, cloud-hosted financial tracking application designed to streamline ledger entries and automate financial data management using AI integrations.

## 🛠️ Tech Stack & Architecture
* **Frontend:** React, Vite, JavaScript, CSS
* **Backend & Database:** Supabase (Relational Database, Real-time Sync, Auth)
* **Hosting & CI/CD:** Vercel, GitHub
* **Integrations:** AI API endpoints for automated financial data parsing (e.g., Deepgram)

## ✨ Key Features
* **Cloud Database Synchronization:** Real-time data storage and retrieval utilizing Supabase.
* **AI-Assisted Workflows:** Integrated voice/text parsing to automate ledger entry creation.
* **Responsive Dashboard:** Clean, user-friendly UI for tracking financial metrics and history.
* **Automated Deployment:** CI/CD pipeline configured through Vercel for zero-downtime updates.
